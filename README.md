# Beast 🐺

**A small programming language in beast mode.**

Beast is a dynamically-typed scripting language with a bytecode VM written in
portable C11 — no dependencies, one `make` away. It is built for one thing:
being a genuinely fast interpreter you can read in an afternoon. On
compute-bound workloads it runs several times faster than CPython, and it is
honest about where it doesn't.

```beast
#!/usr/bin/env beast

fn fib(n) {
    if n < 2 { return n }
    return fib(n - 1) + fib(n - 2)
}

fn make_counter(start) {
    let n = start
    return fn(step) { n += step; return n }   # a real closure
}

let tick = make_counter(100)
print(tick(1))          # 101
print(tick(2))          # 103

let counts = {}
let words = ["ox", "wolf", "ox", "bear", "wolf", "ox"]
for i in 0..len(words) {
    let w = words[i]
    counts[w] = get(counts, w, 0) + 1
}
print(counts["ox"])     # 3
print(fib(30))          # 832040
```

---

## Why Beast

- **Fast by construction.** NaN-boxed 8-byte values, computed-goto dispatch,
  a fused range-for opcode, compile-time slot addressing, and zero-copy call
  frames. The speed is in the architecture, not an optimizer.
- **Tiny and dependency-free.** The whole toolchain is ~3,900 lines of C11
  built with `gcc`/`make`. No libraries, no build system beyond a Makefile.
- **Terse but footgun-free.** Newline-terminated statements (no semicolons),
  no parentheses around conditions, `let`/`fn`. But also: only `nil`/`false`
  are falsey, `==` never coerces, assignment is a statement, and a misspelled
  global is a *compile* error with a "did you mean".
- **Diagnostics are a feature.** Compile errors show `file:line:col`, the
  source line, a caret, and a fix hint. Runtime errors print a stack trace.
- **Honest benchmarks.** Every number below is generated by `make bench`
  against CPython — including the workload where Beast loses.

## Quick start

```sh
git clone <this repo> && cd Beast-mode
make                       # builds build/beast
./build/beast examples/mandelbrot.bst
./build/beast              # start a REPL
```

Run a file, drop into a REPL, or dump bytecode:

```sh
beast script.bst           # run a program
beast                      # REPL
beast -d script.bst        # disassemble instead of running
BEAST_GC_STRESS=1 beast script.bst   # collect on every allocation
```

## Benchmarks

`make bench` — best of 5 runs, Python 3.11, speedup = Python ÷ Beast (higher
is faster):

| Benchmark   | Stresses                    | Speedup vs CPython |
|-------------|-----------------------------|--------------------|
| `loop`      | Tight numeric range-for     | **~8.7×**          |
| `fib`       | Function-call throughput    | **~1.9×**          |
| `wordcount` | Map insert/lookup churn     | **~1.9×**          |
| `trees`     | Allocation / GC churn       | **~1.6×**          |
| `sieve`     | Array index get/set         | ~1.1×              |
| `strings`   | String concat in a loop     | ~0.3× (slower)     |

The big wins come from the fused `OP_FOR_RANGE` opcode and unboxed
arithmetic. The `strings` loss is the flip side of interning every string:
concatenating in a loop pays a hash and a table probe each time. That
tradeoff, and the rest of the architecture, is written up in
[`docs/DESIGN.md`](docs/DESIGN.md).

## A tour of the language

```beast
# Variables and the seven types.
let n = 42                      # num  (one IEEE-754 double type)
let s = "beast"                 # str  (immutable, interned)
let a = [1, 2, 3]               # array
let m = { name: "rex", legs: 4 }  # map (bare keys are string sugar)
let f = fn(x) { return x * x }  # fn   (first-class)
let ok = true                   # bool
let nothing = nil               # nil

# Maps: dot and bracket are the same field.
m.tail = true
print(m.name)                   # rex
print(get(m, "wings", "none"))  # none   (default for a missing key)

# Control flow: no parens, braces required.
if n > 10 and s == "beast" {
    print("big beast")
}

# The only loop over data: a half-open integer range.
let total = 0
for i in 0..len(a) {
    total += a[i]
}

# while, break, continue, and the and/or ternary idiom.
let i = 0
while true {
    i += 1
    if i % 2 == 0 { continue }
    if i * i > 50 { break }
}
let size = len(a) > 2 and "long" or "short"

# Closures capture by reference; recursion and mutual recursion just work.
fn is_even(k) { if k == 0 { return true }  return is_odd(k - 1) }
fn is_odd(k)  { if k == 0 { return false } return is_even(k - 1) }
```

See [`examples/`](examples/) for FizzBuzz, a sieve, quicksort, a word counter,
closures-as-objects, and an ASCII Mandelbrot renderer.

## Building and testing

```sh
make            # release build -> build/beast
make test       # run the test suite
make test-all   # run tests under release, ASan/UBSan, GC-stress, and the
                # tagged-union (no-NaN-boxing) fallback build
make bench      # benchmark vs python3
make loc        # count lines of C
make debug      # ASan/UBSan build -> build/beast-debug
```

The test suite passes under all four configurations, including
AddressSanitizer + UndefinedBehaviorSanitizer with GC stress — the real
correctness signal for a hand-written VM.

## Status

Beast is **v0.1** — small on purpose. Classes, modules, exceptions, an integer
type, string interpolation, and iterators are intentionally absent; several
are reserved words (`class const import match try`) so they can be added later
without breaking your code. The design rationale for every cut is in
[`docs/DESIGN.md`](docs/DESIGN.md).
